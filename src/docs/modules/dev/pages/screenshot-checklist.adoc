= Screenshot checklist
Paul Snow
0.0.0
:description: The screenshots the end-user documentation wants, with the filename each should be saved as and the screen to capture it from.

The end-user guide (`ROOT` module) describes RepFoundry's screens in prose only — none of its pages currently contain an `image::` directive. This page is the input to a follow-up capture pass: it lists every screenshot those pages want, the filename each should be saved as, and which screen and state to capture it from.

IMPORTANT: No page may reference any of these images until the corresponding file actually exists under the images directory. The Antora build used in CI (`--log-failure-level=warn`) fails on a missing image, so adding an `image::` directive ahead of the file would break the build. Capture the screenshot first, add the file, then wire up the reference.

Filenames below are plain text — this page does not embed them with `image::`, so their absence does not affect the build.
